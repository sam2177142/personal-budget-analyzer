# Personal Budget Analyzer

## Project Overview

The Personal Budget Analyzer is an interactive Streamlit application
that helps users track their income, expenses, and spending habits.
Users can upload their own transaction data or explore the included
sample dataset.

## Features

- Upload a CSV file containing transactions
- Filter transactions by month and category
- Set a monthly spending budget
- View total income, expenses, and remaining money
- Visualize spending by category and daily spending trends
- Download filtered transactions

## Technologies Used

- Python
- Streamlit
- Pandas

## Dataset

The included sample dataset contains fictional income and expense
transactions. Positive amounts represent income, and negative
amounts represent expenses.
